Remove specific URLs (posts, pages or any custom post type) from the llms.txt file generated by SEOPress PRO, without affecting search engine indexing.

== Description ==

SEOPress PRO can generate a virtual llms.txt file using placeholders such as `{{latest_posts:5}}`, but it offers no way to leave out individual URLs. This plugin adds a settings screen where you can exclude any URL from llms.txt.

* Works with posts, pages and any public custom post type.
* Paste URLs, search content by title, or tick links currently in llms.txt.
* Only llms.txt is changed. No noindex is added; XML sitemaps and robots.txt are untouched, so Google indexing is not affected.
* Internal URLs are stored as paths, so exclusions keep working after a staging site is pushed live.
* Clears the cached llms.txt in WP Rocket and SiteGround Optimizer on save.
* Active only while SEOPress PRO is active and its llms.txt feature is enabled.

== Installation ==

1. Upload the plugin zip via Plugins > Add New > Upload Plugin, or extract it to `/wp-content/plugins/llms-txt-url-exclusions-for-seopress-pro/`.
2. Activate the plugin.
3. Make sure SEOPress PRO is active and llms.txt is enabled (SEO > PRO > llms.txt).
4. Go to SEO > llms.txt Exclusions, add the URLs to exclude and click Save Changes.

== Frequently Asked Questions ==

= Will excluded pages be removed from Google? =

No. The plugin only removes the lines from llms.txt. Robots meta, canonical tags, sitemaps and robots.txt are not modified.

= What does the settings page show if SEOPress PRO is missing? =

"Please Install/Activate SEOPress PRO plugin." If SEOPress PRO is active but llms.txt is off, it shows "Please enable llms.txt from SEOPress PRO first."

= I saved but still see the URL =

Your llms.txt may be cached by a server or CDN cache. Purge it, or open `/llms.txt?nocache=1` to check the live output.
